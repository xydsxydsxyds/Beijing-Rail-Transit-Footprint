# 北京轨道交通足迹地图

一款在浏览器中记录北京轨道交通乘车足迹的交互式地图。你可以分别标记乘坐过的区间，以及实际上下车或换乘过的车站，并实时查看里程、线路覆盖率、行政区覆盖、地理极限和足迹积分。

## 在线体验

无需安装，直接访问：

**[打开北京轨道交通足迹地图](https://xydsxydsxyds.github.io/Beijing-Rail-Transit-Footprint/)**

为保证效果，建议在 PC 端访问，使用较新版本的 Chrome、Edge、Firefox 或 Safari。首次打开需要下载线网数据和字体，请稍候片刻。

## 主要功能

- 在交互式线路图上点选已乘区间和到访车站；
- 支持整条线路快速标记或取消；
- 分别记录上下车、站内换乘和出站换乘；
- 自动计算精确乘坐里程、车站与区间覆盖率、行政区覆盖和积分；
- 展示足迹中的最东、最西、最南、最北车站及地理跨度；
- 支持创建、复制、重命名和切换多份足迹；
- 足迹自动保存在当前浏览器中；
- 支持导入、导出 JSON，以及导出 SVG、PNG 和 Excel 统计报告；
- 到访特定车站后可解锁线路图彩蛋。

西郊线、亦庄 T1 线部分区间存在双向距离数据差异，本项目取两个方向公布距离的平均值。首都机场线采用专项组合里程规则，避免环形运行区间被简单重复累计，详见 `src/mileage.js`。

## 使用方法

1. 打开在线网站，等待全网数据加载完成。
2. 点击车站，将其标记为到访；再次点击可取消。
3. 点击线路区间，将其标记为已乘；如果区间不便点选，可切换至“区间点选”模式。
4. 在页面下方查看覆盖率、里程、行政区和积分统计。
5. 使用“导出 JSON”定期备份足迹；需要在其他浏览器或设备继续使用时，再导入该文件。

列车只是经过、但没有上下车或换乘的车站不计为到访。每段连续乘坐区间的起点和终点通常应标记为到访，应用会在导出前提示可能不一致的记录。

## 数据与隐私

足迹保存在浏览器当前站点的 IndexedDB 中，不会自动上传到服务器。清除浏览器网站数据、更换浏览器、域名或设备可能导致本地记录不可用，请提前导出 JSON 备份。

数据口径截至 2026-06-30，包含官方线路图范围内的地铁、机场线和有轨电车，不包含市郊铁路。项目与北京地铁及相关运营单位无隶属或授权关系。

## 技术栈

项目是无需后端的静态 Web 应用，主要使用：

- HTML、CSS 和原生 JavaScript ES Modules；
- SVG 线路图与浏览器 Canvas 图片导出；
- IndexedDB 本地数据存储；
- JSON Schema、AJV 数据校验；
- Node.js 内置测试运行器及数据构建脚本；
- GitHub Actions 和 GitHub Pages 自动部署。

## 本地运行

需要 Node.js 18 或更高版本：

```powershell
npm install
npm run dev
```

然后访问 `http://127.0.0.1:4173/`。请勿直接双击 `index.html`，浏览器的本地文件安全策略会阻止读取 JSON 数据。

运行自动化测试：

```powershell
npm test
```
